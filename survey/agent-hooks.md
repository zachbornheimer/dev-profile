`apps/agent-hooks` is the live catalog for the agent-hooks dispatcher, tracked as `~/.config/agent-hooks` (`track`, `encrypt = true`, `exclude = ["*.bak*"]`). `hooks.toml` has 70 `[[hooks]]` rows and a `[defaults]` table that fans out to eight agents (claude, codex, gemini, grok, hermes, copilot, opencode, mastra). Rows bind an event (`tool.before`, `tool.after`, `session.start`, `prompt.submit`, `turn.stop`, `context.compact.before`, `subagent.stop`, `worktree.create` and `worktree.remove`) to either a script under `~/.agents/hooks/` (the `agents/hooks/` tree) or a native `policy` name; 17 rows use `policy`. 25 rows set `on_failure = "block"`, mostly pre-tool guards (quality-guard, work-order-gate, main-branch-guard, gate-bypass-tripwire, shared-checkout-guard and others). Other rows record bash, edit and agent-spawn signatures, run the completion gate and Stop-time nudges at turn end, recall goals and memory at session start, run atask context, and call hindsight hooks per agent. `hooks.toml.bak-20261021-003314` is an older copy: 61 rows, absolute `/Users/zbornheimer/...` paths, and `shell = false` argv commands for the grok hindsight rows.
