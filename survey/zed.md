`apps/zed` is the Zed editor config, tracked as `~/.config/zed`. `settings.json` docks the project, outline, collaboration and git panels left and the agent panel right, defaults the agent to Cerebras `llama3.1-8b` without thinking, registers `claude-acp` from the registry, and turns on vim mode with the VSCode base keymap. It also sets autosave after 1 s, hides the minimap, uses Berkeley Mono Variable with fallbacks, and switches between GitHub Light and One Dark with the system. `session.trust_all_worktrees` is `true`. `prompts/prompts-library-db.0.mdb/` is Zed's LMDB prompt library (`data.mdb`, `lock.mdb`), a binary database that makes up most of the directory's 60 KB.

No test targets it. `config/mise.toml` is the only reference (`track`, `encrypt = true`). The `settings.json` file is JSONC (comments and trailing commas), which a strict JSON linter would reject. Zed writes the LMDB files itself, so they are state, not config.
