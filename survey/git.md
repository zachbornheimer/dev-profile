`apps/git` holds `ignore`, the global gitignore (`~/.config/git/ignore`), which applies to every repository on the machine. It groups rules by source: macOS junk (`.DS_Store`, `._*`, Spotlight and Trash folders, the `Icon` file), editor and temp files, Python caches, Node and framework build caches (`.next`, `.turbo`, `.vercel` and others), AI-agent workspace dirs (`.claude/`, `.opencode/`, `.agents/`, `.generated/`, `.trunk/`), Beads and Dolt state, Terraform local state (the lock file stays tracked), and Windows files. Rules a project shares belong in that project's own `.gitignore`.

No test covers it. `config/mise.toml` is the only referrer (`track`, `encrypt = true`). The header suggests `git check-ignore -v <path>` for debugging, which is the manual way to verify a rule.
