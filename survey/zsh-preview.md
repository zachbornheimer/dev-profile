`apps/zsh-preview` is a preview-only zsh setup that shows a prompt and the local dev URL for a checkout, tracked as `~/.config/zsh-preview`. `.zshrc` sources the normal `~/.zshrc` and then `prompt.zsh`, and prints a legend for the prompt markers. `routes.zsh` discovers the URL: `preview::dev-url` reads the dev family's pidfile under `~/.cache/dev-profile/dev` and builds the `.localhost` URL. If there is none, `preview::urls` matches portless routes from `~/.portless/routes.json` to processes whose cwd is inside the checkout, using `lsof`, and picks http or https and the port from the portless proxy files. `prompt.zsh` sets the color table and `preview::header` and `preview::width`, used to lay out Starship's header without competing prompt hooks. `.zcompdump` is a 51 KB generated zsh completion cache (1063 files, zsh 5.9), which is an artifact.

No test in the repo targets it, though `tests/shell-init-fixture.sh` and `tests/profile-layout.sh` cover nearby shell setup; I did not check whether they cover these files. The route logic is pure shell with injectable state (`PORTLESS_STATE_DIR`, `XDG_CACHE_HOME`), which would make it testable, but no fixture does it. `.zcompdump` is tracked in git (`git ls-files` lists it), which is likely unintended for a generated cache.
