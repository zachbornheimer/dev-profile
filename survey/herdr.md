`apps/herdr` configures the herdr terminal multiplexer: `config.toml`, `oneshot.sh` and `session-tokens.py`, each mapped separately by `config/mise.toml` into `~/.config/herdr/`. `config.toml` sets a rose-pine theme that follows host appearance (dark and light variants with custom colors), symbol status indicators, a 32-column sidebar, one-row agent and space entries, and prefix keys (`ctrl+space`, `shift+space`) with popup commands and herdr-nvim plugin actions. `oneshot.sh` backs the `prefix+!` popup: it asks (via `gum`) for a prompt and an omp model level (`@default`, `@smol`, `@slow`), creates a tab in a dedicated `one-shots` herdr session, and runs `omp` with the prompt passed as an `@file`. `--reap` closes tabs unused for `ONESHOT_TTL_SECONDS` (default 24 h), judged by pane-output hash and agent status. `session-tokens.py` visits every running herdr session and reports each agent's short session id as pane metadata (TTL 180 s) so the sidebar can render `$session`. It hardcodes `/opt/homebrew/bin/herdr`.

No test in this repo runs these scripts. The only references are `config/mise.toml` and the repo-wide linters (shell and Python checks). `oneshot.sh` has documented test hooks (`ONESHOT_PROMPT`, `ONESHOT_MODEL`, `ONESHOT_IS_ONE_SHOT`, `ONESHOT_SESSION`, `ONESHOT_DIR`, `ONESHOT_TTL_SECONDS`) that let it run without `gum`, but no fixture uses them here. `session-tokens.py` exits 0 and prints a skip line when herdr is not running, so scheduler failures stay quiet.
