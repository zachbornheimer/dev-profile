# Deep path

Load only when `route` printed `depth=deep`. Quick asks never read this file.

Do not create `research_notes/` or `reports/` in the repo. That is the synced deep-research skill, and it is the wrong default.

## Workers

`route` already set `workers` (3, or 1 if he said "a subagent"). One angle each. Mutually exclusive. Pass the decision, the `not_before` date, and the source order: official docs, then vendor or GitHub, then secondary.

One extra round only if a fetched page names a primary source you have not opened. Then stop, even if a gap remains. Label the gap.

## Brief

Write one file. If he named a path, use that. Otherwise `~/Downloads/research/<title>.md`.

Title: 3 to 6 words, sentence case, letters numbers and spaces only, under 50 characters. Do not reuse an existing filename in that folder.

Required headings, in order:

- `Researched: YYYY-MM-DD`
- `## Question`
- `## Findings` — each claim has URL, source date, retrieval date, a `quote`-checked quote, and tier (`official`, `vendor`, `secondary`)
- `## Recommendation`
- `## Open questions`
- `## Sources`

Read the file back. If a heading or a quote check is missing, do not tell him it is done.

## Chat

First line is the path. Then the recommendation, the deciding fact, and what would flip it. Do not paste the brief.
