# TypeSafe effective-use skill

This package turns the TypeSafe documentation, patterns, demo, and current cookbook set into an agent-oriented skill with focused local examples.

- `SKILL.md` contains the durable design rules plus a proactive opportunity scan.
- `examples/INDEX.md` maps common code/design smells to the closest examples.
- `examples/00-Opportunity-Discovery.md` teaches the agent how to generalize beyond named cookbooks.
- `examples/01`–`28` cover foundations, documented patterns, the Smart Home demo, and every current official cookbook.
- `examples/29`–`36` are cross-domain opportunity examples derived from the official use-case map and cookbook patterns.
- `examples/37` covers opt-in images and the Box primitive (Jev 1.14).
- `SOURCES.md` maps the package to official TypeSafe sources and the confirmed Smart Home Loom video.

The examples are not a whitelist. They are intended to help an agent recognize reusable decision shapes in unfamiliar domains.

Prefer the linked live TypeSafe documentation for current API contracts, SDK details, model versions, limits, pricing, and benchmark numbers.
