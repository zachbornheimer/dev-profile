# Change log entry template

Append-only. One entry per change, added to the site's `change-log.md` (kept in the client's vault folder, not a git repo). Never edit old entries; add a correction entry.

```text
## <YYYY-MM-DD HH:MM TZ> - <short title>
- Site / tier:
- Finding ID(s):
- What changed (before -> after, versions):
- Backup location / rollback command:
- Probes after (pass/fail list):
- Rollback needed? (yes/no, what):
- Linear issue:
- Site bible updated? (yes/no)
```
