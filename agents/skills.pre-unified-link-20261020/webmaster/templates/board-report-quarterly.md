# Quarterly board report template

One page for the board. Audience is non-technical.

```
<Site> website report - <Quarter> <Year>

1. Bottom line: <healthy / needs attention>, in one sentence.
2. Availability: uptime %, longest outage (date, duration, cause).
3. Safety: updates applied, vulnerabilities found and fixed, backup restore test result (date, pass/fail).
4. Money: donation/registration/membership flow checks passed; failed renewals recovered; dispute rate.
5. Visitors: sessions, top pages, search visibility trend (Search Console), one notable change.
6. Compliance: accessibility status, privacy policy review date, cookie/consent status.
7. Decisions for the board (max 2): <ask, cost, recommendation>.
8. Next quarter: <top 3 priorities>.
```

Rules: numbers compare to last quarter; no jargon; every red item has an owner and a date.
