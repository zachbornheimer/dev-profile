# Voice and copy rules

1. **Plain, second person.** "Anything you customize on a page is kept." / "Only your own next page load is profiled."
2. **Concrete numbers.** "1 normal request in 50", "trimmed to about 155 characters", "shows the 20 slowest", "The title is 113 characters. Search results show about 60."
3. **Say what happens and what is stored.** "A healthy request writes nothing." / "The key is encrypted before it's saved. It stays on this site, is sent only to Claude, and isn't shown again after you save it."
4. **State the safe default.** "Nothing is deleted." / "Nothing changes until you click Apply." / "Off by default."
5. **Healthy states are sentences.** "No remote call is failing repeatedly." / "No request started a shell command." / "Looks good. There's nothing you need to do."
6. **Sentence case everywhere.** "Recent over-budget requests", "Turn monitoring off", "Show all 20 requests".
7. **Meta lines use "·".** "Last saved 1 minute ago · 13 routes · 20 over-budget requests in the last 12 minutes" / "Budgets: REST 800 ms · admin and AJAX 2000 ms".
8. **Buttons are verbs.** "Connect AI", "Check access", "Rebuild", "Disconnect", "Delete everything". Destructive prompts name the confirmation: "Asks you to type DELETE first."
9. **Explain absence.** "Nothing published yet." / "Nothing to review here." / "Demand not verified".
10. **Units with a space.** "800 ms", "2.30 s", "$1.84 this month". Ratios use "×": "3.4×".
