A sortable table of routes with a distribution column.

Head cells are 12px muted; the active sort column shows an arrow only ("p95 ↓"). Rows use a 9px 20px padding with a `color-row-divider` rule and a `color-surface-subtle` hover. Numbers are right-aligned with tabular numbers; a route cell pairs a TypeBadge with the route in mono. The consumer provides the rows and the scale of the distribution column.
