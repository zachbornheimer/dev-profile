Monitoring

On, set by the site's code through a filter

When on, every admin, REST, and AJAX request is measured as it ends. Only slow or unusual requests are saved, plus 1 normal request in 50 for comparison. A healthy request writes nothing.

Profile my next page load

Works with monitoring off

Times every plugin and theme callback on your next admin page load, once, and shows the 20 slowest. Only your own next page load is profiled.
