A switch and a checkbox for on and off settings.

The switch is a 36px pill: `color-switch-off` when off, `color-accent` when on, with a white knob. Shown alone, as a checkbox consent line, and with a label and help line ("Allow edits to page content", "Needed for internal links and heading fixes. Off by default."). The consumer provides the label, the help and the state; say the safe default in the help.
