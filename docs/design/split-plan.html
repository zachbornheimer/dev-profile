Goal

One repo got two jobs. This splits them. The dev profile holds everything that changes how you develop. The dotfiles repo holds everything else that makes this Mac this Mac. Secrets stay in 1Password and neither repo stores them.

Today both live in dev-profile, and ~/.agents is one link into it. If you lost this Mac, nothing would rebuild it in one step.

Dev profile public · ~/Developer/Personal/dev-profile

  • Tool pins, one file per language: Go, Python, JS/TS, Rust, Docker, Terraform, PHP, Swift, Perl
  • The task contract: setup lint test scan ci and the rest
  • hk hooks written by hand, with each tool's config passed explicitly
  • dprint, golangci, deny, yamllint, markdownlint, gitleaks
  • Git hook keys, active only under ~/Developer/Personal
  • worktrunk and its aliases, wt-sync, workz, portless, the dev:* tasks
  • nvim's conform, and the hook that lets wt switch change directory
  • Agent coding rules, enforcement hooks, and 5 workflow skills

Dotfiles private · ~/Developer/Personal/dotfiles

  • The rest of zsh, nvim, and kitty
  • App configs: zed, bat, atuin, lazygit, htop, btop, ripgrep, direnv, 1Password, opencode
  • ~/.gitconfig (name and aliases), tmux, vim, profile
  • LaunchAgents, macOS setup scripts, personal Homebrew packages
  • Your agent setup: AGENTS.md, models, advisors, MCP servers, personal skills and the skill lock file
  • Agent state stays untracked

No editorconfig in either repo.

Rebuilding a Mac what the plan makes true

1

Install Homebrew and mise.

2

Clone the dotfiles repo and link it as ~/.config/mise/conf.d/dotfiles.

3

Run mise bootstrap. It clones dev-profile, installs packages and LaunchAgents, and links both repos' files into place.

mise bootstrap --adopt is not used yet. Without a sync marker it would clone the repo into ~/.config/mise. It comes back with automatic sync.

What could go wrong each has a test in the plan

  • A fresh Mac between cloning dotfiles and cloning dev-profile breaks mise
  • Running apply from a worktree points live links at the worktree
  • Profile tasks or hooks leak into repos outside ~/Developer/Personal
  • A personal or untracked file stays in the public repo
  • A reinstall overwrites a skill you edited
