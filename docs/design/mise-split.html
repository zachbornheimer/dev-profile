Why the settings did not move

mise accepts only these keys in an included file: [tools], [tool_alias], [env], [vars], [hooks], [shell_alias], [plugins], [wrappers], [bootstrap], min_version and [_]. Anything else is an error, and [settings] is in that group — so the entry keeps it and only the pins move. The layout test asserts the settings still apply, which is what catches someone moving them into an include later.
